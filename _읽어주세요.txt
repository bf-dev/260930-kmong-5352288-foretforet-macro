포레포레 오픈 구매 매크로 사용 안내

[준비]
1. ZIP 파일을 원하는 폴더에 압축 해제합니다. (바탕화면 등 아무 곳이나 괜찮습니다)
2. 폴더 안의 foretforet-macro.exe 를 더블클릭해서 실행합니다.
   - _internal 폴더는 지우거나 옮기지 마세요. exe 와 같은 폴더에 있어야 합니다.
   - 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행] 을 누르세요.
3. PC에 Microsoft Edge 또는 Chrome 이 설치되어 있어야 합니다. (윈도우 기본 Edge 로 충분합니다)

[1. 구매할 상품]
- 한 줄이 상품 하나입니다. [+ 상품 추가] 로 줄을 늘리고, [삭제] 로 지웁니다.
- 상품 주소는 모바일(/m/product.html?branduid=...), PC(/shop/shopdetail.html?branduid=...) 둘 다 됩니다.
- [옵션] 버튼(또는 [옵션 전체 불러오기])을 누르면 사이트에서 사이즈 목록과 재고를 가져옵니다.
  목록에서 원하는 사이즈를 고르세요.
- 수량 칸에 살 개수를 적습니다.
- 사용 체크를 끄거나 수량을 0 으로 하면 그 줄은 건너뜁니다. 주소와 사이즈는 그대로 남아 있어서
  다시 체크만 하면 됩니다.
- 입력한 내용은 자동 저장되어 다음 실행 때 그대로 나옵니다.

[2. 오픈 시각]
- 한국시간으로 적습니다. 예: 2026-10-01 10:00:00
- 프로그램이 쇼핑몰 서버 시계에 맞춰서 정각에 장바구니에 담습니다.

[3. 로그인]
- 로그인 방식(네이버/카카오/포레포레 자체)을 고르고 아이디, 비밀번호를 입력합니다.
- [로그인 테스트] 를 미리 한 번 눌러 보세요. 브라우저 창이 열리고 로그인됩니다.
  네이버 새 기기 인증, 캡차 등이 나오면 열린 창에서 직접 진행하시면 됩니다.
  한 번 로그인되면 다음부터는 로그인 상태가 유지됩니다.
- 비밀번호는 저장하지 않습니다. 실행할 때마다 입력해 주세요.

[4. 결제]
- 기본: 장바구니에 담고 주문서 화면까지 간 뒤 멈춥니다. 열린 창에서 직접 결제하세요.
  (카드 결제는 결제창이 뜨므로 직접 진행해야 합니다)
- [무통장입금으로 주문까지 자동 완료] 를 체크하면 무통장입금으로 주문 완료까지 자동 진행합니다.
  입금자명을 적어 두세요.

[시작]
- 오픈 3분 이상 전에 [시작 (오픈 대기)] 를 누르세요.
  3분 전에 로그인과 상품 페이지를 미리 열어 두고, 정각에 모든 상품을 담습니다.
- 대기열(접속 대기) 화면이 뜨면 새로고침하지 않고 순번을 기다립니다. 순번은 로그에 표시됩니다.
- 품절되거나 옵션이 없으면 로그에 표시하고 나머지 상품은 계속 진행합니다.
- 주문서 화면이 뜨면 브라우저 창을 닫지 말고 바로 결제하세요.
- 중간에 멈추려면 [중지] 를 누릅니다.

[문의]
- 실행 기록은 문제 확인을 위해 자동으로 전송됩니다. (비밀번호는 전송하지 않습니다)
- 문제가 생기면 크몽 메시지로 알려 주세요.
- 새 버전이 나오면 실행 시 업데이트 안내가 표시됩니다.
